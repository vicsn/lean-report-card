About

If we want mathematical collaboration to scale, improving code quality will be a key unlock. Software engineering choices in Lean — how a theorem is stated, which instances are registered globally, how modules are split — show up as compilation time and memory for everyone downstream. Readers who want to learn more about that influence can start from The Cost of a Lemma.

Lean Report Card is a modest attempt at indexing code quality of Lean repositories. It is open source and a work in progress - if you have ideas for enhancing code quality and security then do reach out!

The current grade is a deterministic total from 0 to 100. If you have a public git repository, you can submit it for analysis and, if you allow publication, keep the result on the index and as a badge on GitHub or another Lean project registry.

The site was inspired by Go Report Card and Rust Report Card, and by public SSL checking services such as Qualys SSL Labs and SSL Shopper.
